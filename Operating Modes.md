# Operating Modes

Two modes the patient (and the LLM helping them) switches between.

## Architect mode (every ~2 weeks)

Analyze, question, re-plan, read evidence.

- Open the dashboard. Review trend lines, not single points.
- Question current protocols: which ones earned their cost this cycle? Which look like ritual without payoff?
- Re-read recent literature relevant to active questions (one or two specific things, not "catch up on health").
- Update Medical Profile if a protocol changed.
- Schedule the next control point (lab re-test, imaging, etc.).

This mode is **explicit and time-bounded** — it's not "I'll think about my health when I have time", it's a scheduled slot.

## Operator mode (daily)

Execute the plan without overthinking. Trust the system. Reduce anxiety via trust, not via re-analysis.

- Don't re-litigate the supplement stack at breakfast.
- Don't audit yesterday's HRV before the morning walk — log it, move on.
- New information goes into a "next architect session" note, not into mid-day protocol changes.

## Why the split matters

Mixing the modes is the most common failure pattern:
- Mid-week protocol tweaks → no clean signal, no real measurement.
- Constant re-evaluation → decision fatigue, drop adherence.
- Skipping architect mode → drift; protocols don't update with new lab data; cruft accumulates.

## Heuristic: Mood follows metabolism

When the patient (or the operator on their behalf) starts feeling off, the first check isn't psychology — it's:
1. Sleep (last 3 nights, not last 1)
2. Overtraining / under-recovery (HRV trend)
3. Glucose excursions / late meals / alcohol
4. Hydration / electrolytes
5. Then relationships / meaning / cognitive load

Most "I feel anxious / unmotivated / brain-foggy" episodes resolve on layer 1-3 before psychological framing is even needed.
